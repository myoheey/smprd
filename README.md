# 바이브코딩으로 만드는 나만의 학습도구 — 실습 자료

숙명여자대학교 학내 구성원 대상 AI 특강 실습 자료 웹페이지.

| 페이지 | 내용 |
|---|---|
| `index.html` | 자료 목록 |
| `prd.html` | 실습 자료 1 · 학습도구 PRD 워크시트 (복사 버튼, PRD 바로 작성, 체크리스트) |
| `fix.html` | 실습 자료 2 · 수정 요청 프롬프트 모음 |
| `tools.html` | 실습 자료 3 · 도구별 실습 안내서 (Gemini · ChatGPT · Claude 탭) |
