STEP 3 · 20분

자동으로 굴러가게

PRD의 ⑧ 실행 조건을 실제 일정으로 바꿈. 계정마다 열려 있는 기능이 다를 수 있어 세 가지 방법을 준비함. A가 안 되면 B, B도 안 되면 C로 진행.

판단하고 행동하는 에이전트를 만들고 싶다면 → Studio 예시 플로우 5종 (메일을 보고 판단해 시트에 기록하는 수업 공지 비서 등)
주소
studio.workspace.google.com (컴퓨터 브라우저)
장점
언제 → 무엇을 → 어디로가 블록으로 보임. 에이전트의 구조를 눈으로 확인 가능
조건
학교 관리자가 Studio를 켜 둔 계정만 사용 가능 · AI 단계는 만 18세 이상
흐름(플로우) 만들기

매주 월요일 8시 복습 브리핑

  1. 새 플로우 만들기
  2. 시작 조건: 일정 → 매주 월요일 오전 8:00
  3. 단계 추가: Gemini에게 물어보기 → 아래 프롬프트 붙여 넣기
  4. 단계 추가: 이메일로 알림 받기(또는 Chat에서 알림 받기) → 앞 단계의 Gemini 응답을 본문에 연결
  5. 테스트 실행 → 시작, 활동 탭에서 결과 확인
  6. 결과가 괜찮으면 사용 설정
Gemini에게 물어보기 단계에 넣을 프롬프트
너는 [과목명] 복습을 돕는 학습 조교다.
아래 핵심 개념 목록에서 이번 주 복습할 개념 3개를 골라,
각각 "두 개념의 차이를 설명해 보라"는 질문으로 만들어라.

[형식]
- 맨 위: 이번 주 복습 질문 3개 (정답 없이 질문만)
- 맨 아래 "확인용 핵심 포인트": 질문별 핵심 요소 2~3개를 짧게
- 전체 10줄 이내

[핵심 개념 목록]
(예: 감각기억/단기기억, 단기기억/장기기억, 부호화/인출, 유지 시연/정교화 시연, 순행간섭/역행간섭)

테스트 실행도 실제로 메일을 보냄. 받는 사람이 나 자신인지 먼저 확인.

위치
Gemini 채팅창에 "매주 ~에 ~해 줘"라고 입력하면 예약 작업이 만들어짐
관리
설정의 예약된 작업에서 확인 · 수정 · 일시중지 · 삭제
조건
계정에 따라 아직 사용할 수 없을 수 있음 · 활동 기록 보관 사용 · 활성 예약은 최대 10개
채팅창에 넣을 예약 프롬프트
매주 월요일 오전 8시에 아래 내용을 실행해 줘.

[과목명] 이번 주 복습 브리핑을 만들어 줘.
1. 아래 핵심 개념 목록에서 3개를 골라, 두 개념의 차이를 설명해 보라는 질문으로 만든다. 정답은 쓰지 않는다.
2. 맨 아래에 질문별 확인용 핵심 포인트를 2~3개씩 짧게 적는다.
3. 내 캘린더에서 이번 주 과제·시험 일정을 찾아 마감이 빠른 순서로 정리한다.

[핵심 개념 목록]
(여기에 붙여 넣기)
  • 캘린더 일정을 읽으려면 Google 캘린더 연결 앱 사용 권한이 필요함. 처음 실행 때 권한을 묻으면 허용.
  • 만들어진 예약 작업은 바로 한 번 실행해 결과를 확인한 뒤 그대로 둠.
언제 쓰나
Studio와 예약 작업이 둘 다 막혀 있을 때
방식
자동 실행은 아니지만 "언제 실행할지"를 설계하는 반자동 방식
Google 캘린더

반복 일정 + 스킬 호출

  1. Google 캘린더에서 매주 월요일 오전 8:00 반복 일정 만들기
  2. 제목: [과목명] 복습 — Gemini에서 /스킬이름
  3. 설명란에 gemini.google.com 링크와 "이번 주 복습 질문 3개 내 줘" 문장 적기
  4. 알림: 10분 전 → 알림이 오면 링크를 열고 스킬 실행
