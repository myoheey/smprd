시연 ①Gemini 작업(Task)과 예약됨(Scheduled)

예전 이름은 Gemini Spark. 지금은 Gemini 입력창 아래 채팅 / 작업(Task) 전환으로 쓰고, 반복 실행은 왼쪽 사이드바의 예약됨(Scheduled)에서 관리함.

작업(Task)

여러 단계를 스스로 계획하고, Gmail·캘린더·Drive 같은 앱과 웹을 오가며 끝까지 처리하는 에이전트. 결과는 확인 후 승인하는 방식.

예약됨(Scheduled)

작업을 정해진 시간에 맞춰 백그라운드에서 반복 실행. 채팅의 예약 작업과는 다른 기능.

내 계정에서 쓰려면 개인 Google 계정 + Google AI Pro 또는 Ultra 구독 + 만 18세 이상 + 활동 기록 보관 사용. 학교 계정에서는 쓸 수 없어 오늘은 강사 시연으로만 진행함.

시연에서 볼 것

STEP 3에서 블록으로 직접 설계한 일을, Task에는 목표 한 문장으로 맡김. 누가 단계를 설계했는지가 차이.

Task에 주는 목표 (시연용)
내 Gmail에서 이번 주에 온 수업 과제·시험 공지를 찾아서
1) 마감일 순서로 과목 · 할 일 · 마감을 표로 정리하고
2) 마감 일정을 내 캘린더에 추가하고
3) 과목마다 과제 전에 떠올려 볼 개념 질문을 2개씩 만들어 줘. 정답은 쓰지 마.
사람이 설계한 플로우 (Studio)

단계가 눈에 보이고 매번 같은 방식으로 실행. 예측 가능하지만 정해진 일만 함.

AI가 계획한 작업 (Task)

처음 보는 상황도 처리하고 방법을 스스로 정함. 유연하지만 과정을 확인하고 승인해야 함.

생각해 볼 질문 — 내 성적과 관련된 일이라면 어느 쪽에 맡기겠는가? 왜?

시연 ②같은 PRD로 학습 앱 만들기 — Google AI Studio

aistudio.google.com의 Build에서 원하는 앱을 말로 설명하면 AI가 앱 전체(화면 + 서버)를 만듦. 대화로 계속 고치고, 코드를 내려받거나 GitHub로 보낼 수 있음.

AI Studio Build에 넣는 프롬프트
아래 PRD로 대학생용 학습 앱을 만들어 줘.

- 한 화면에서 쓰는 웹 앱. 한국어 UI, 휴대폰에서도 보기 좋게.
- 학생이 강의 내용을 붙여 넣으면 Gemini가 개념 차이를 묻는 질문을 하나씩 낸다.
- 학생이 직접 답을 쓰면 빠진 핵심 요소를 힌트로 짚어 준다. 두 번 막히기 전에는 정답을 보여주지 않는다.
- 맞힌 문제 / 다시 볼 문제를 화면에 따로 모아 보여 준다.
- PRD의 금지 사항을 그대로 지킨다.

[PRD]
(STEP 1에서 만든 PRD 붙여 넣기)
  • 학교 계정으로도 Build 사용 가능. 다만 Workspace(학교) 계정은 무료 공개 배포(Publish) 대상이 아니어서, 친구에게 링크로 공개하려면 개인 계정이 필요함.
  • 무료 사용 시 입력 내용이 서비스 개선에 쓰일 수 있음. 개인정보·성적·남의 과제는 넣지 않기.
  • 만든 앱이 Gemini를 부를 때는 만든 사람의 사용량 한도를 씀. 공개하면 방문자 사용량도 내 한도에서 빠짐.

알고 쓰기

  • 자료 업로드 — 개인정보가 담긴 파일은 올리지 않음. 강의자료 활용은 학내 규정 확인.
  • 과제·시험 — 수업별 AI 활용 규정을 먼저 확인. 조교는 공부를 돕는 도구, 대신 하는 도구가 아님.
  • 자동화의 함정 — 복습 질문을 AI가 대신 풀어 주면 기억은 남지 않음. 질문은 자동으로, 떠올리기는 내가.
AI가 대신 떠올려 주면, 기억은 내 것이 되지 않는다. 좋은 학습 조교의 기준은 "내가 더 많이 생각하게 만드는가".
