학습 조교 PRD 워크시트

PRD(요구사항 명세서)는 "무엇을, 누구를 위해, 어떻게, 언제" 할지 정리한 설계서. 잘 쓴 PRD는 스킬, 예약 작업, 다른 AI 도구 어디로든 옮겨 쓸 수 있음.

STEP 1AI 인터뷰로 PRD 작성하기

Gemini 새 채팅에 아래 프롬프트를 붙여 넣음. [대괄호]만 본인 정보로 바꿈. AI가 하나씩 물으면 답하면서 PRD를 완성함.

프롬프트 ① 학습 조교 PRD 인터뷰
너는 대학생의 AI 학습 조교 기획을 돕는 인터뷰어야.
나는 [전공·학년]이고, [과목명]을 공부할 때 쓸 AI 학습 조교를 만들고 싶어.
아래 규칙대로 나를 인터뷰해서 학습 조교 PRD(요구사항 명세서)를 완성해 줘.

[규칙]
1. 질문은 한 번에 하나만 한다. 내 답을 듣고 다음 질문으로 넘어간다.
2. 다음 8개 항목을 순서대로 채운다.
   ① 사용자  ② 해결할 학습 문제  ③ 입력 자료  ④ 처리 절차(핵심 기능)
   ⑤ 출력 형식  ⑥ 금지 사항  ⑦ 성공 기준  ⑧ 실행 조건
3. 내 답이 모호하면 예시를 2~3개 들어 구체화를 돕는다.
   (예: "공부가 잘 안 된다" → 개념을 모르는지, 외워도 잊는지, 문제에 적용이 안 되는지)
4. 핵심 기능은 3개를 넘지 않게 한다. 더 많이 원하면 우선순위를 물어 3개로 줄인다.
5. 기능이 요약·정리 위주라면, 내가 스스로 떠올려 보는 기능
   (퀴즈, 빈칸 채우기, 직접 설명해 보기 등)을 하나 이상 넣자고 제안한다.
6. ⑧ 실행 조건에서는 "언제, 얼마나 자주, 결과를 어디로 받을지"를 묻는다.
   (예: 매주 월요일 오전 8시, 이메일로)
7. 내용을 대신 정하지 않는다. 모든 항목은 내 답에서 나와야 한다.
8. 8개 항목이 모두 채워지면 아래 [PRD 형식]으로 정리하고,
   빠진 내용이나 서로 충돌하는 내용이 있는지 점검해 알려 준다.

[PRD 형식]
# 학습 조교 이름:
## ① 사용자
## ② 해결할 학습 문제
## ③ 입력 자료
## ④ 처리 절차 (핵심 기능 최대 3개, 우선순위 순)
## ⑤ 출력 형식
## ⑥ 금지 사항
## ⑦ 성공 기준
## ⑧ 실행 조건 (언제 · 얼마나 자주 · 어디로)

이제 첫 질문부터 시작해 줘.

인터뷰가 잘 안 될 때

  • 질문을 여러 개 한꺼번에 하면: "질문은 하나씩만 해 줘"
  • 내용을 마음대로 채우면: "내가 말한 내용만으로 다시 정리해 줘"
  • 답이 떠오르지 않으면: "예시를 3개 보여 줘" → 가장 가까운 것을 고쳐서 답하기

PRD 바로 작성

인터뷰 결과를 옮겨 적거나 직접 작성함. 이 브라우저에만 임시 저장되며, PRD 복사를 누르면 위 형식 그대로 복사됨.

한 줄로 무엇을 하는 조교인지 드러나게
누가, 어떤 상황에서 쓰는가?
지금 공부에서 무엇이 막히는가? 증상을 구체적으로
조교가 참고할 자료는 무엇인가?
조교가 어떤 순서로 도와야 하나? 핵심 기능 3개 이내
결과를 어떤 모양으로 받고 싶은가?
조교가 하면 안 되는 것은?
제대로 작동한다는 것을 어떻게 확인할까?
언제, 얼마나 자주, 결과를 어디로 받을까?
공용 PC라면 실습 후 "모두 지우기"를 눌러 주세요.

넘어가기 전 체크리스트

PRD 완성 예시

교양 심리학 수강생의 예시. 과목이 달라도 각 항목의 구체성 수준을 참고함.

완성 예시 — 기억 이론 인출 튜터
# 학습 조교 이름: 기억 이론 인출 튜터
## ① 사용자
교양 「심리학의 이해」 수강 2학년. 중간고사 2주 전, 하루 20분씩 복습할 때 사용.
## ② 해결할 학습 문제
용어(작업기억, 장기기억, 부호화, 인출)는 알지만 두 개념의 차이를 설명하라는
서술형 문제에서 막힘. 읽을 때는 아는 것 같은데 직접 쓰면 안 나옴.
## ③ 입력 자료
4~6주차 강의 슬라이드(PDF 3개).
## ④ 처리 절차 (우선순위 순)
1. 두 개념의 차이를 묻는 질문을 한 번에 하나씩 낸다.
2. 내가 쓴 설명을 읽고, 빠진 핵심 요소를 힌트로 짚어 준다.
3. 두 번 더 막히면 그때 모범 답안과 근거 슬라이드 번호를 보여 준다.
## ⑤ 출력 형식
한 번에 한 질문. 피드백은 3줄 이내, 근거 슬라이드 번호 포함.
## ⑥ 금지 사항
- 내가 답하기 전에 정답을 먼저 보여주지 않는다.
- 입력 자료에 없는 내용을 지어내지 않는다. 자료에 없으면 "자료에 없음"이라고 말한다.
## ⑦ 성공 기준
- 첫 답변에서 정답 대신 질문이나 힌트로 되묻는다.
- 모든 피드백에 근거 슬라이드 번호가 붙어 있다.
## ⑧ 실행 조건
매주 월요일 오전 8시, 지난주 핵심 개념 3개를 묻는 복습 브리핑을 이메일로 받는다.
  • 학습 문제가 증상까지 구체적임 — "읽을 땐 아는데 직접 쓰면 안 나온다"
  • 처리 절차가 인출 중심임 — 정답을 바로 주지 않고, 두 번 막힐 때까지 힌트로 되묻는다
  • 실행 조건이 그대로 자동화 설정이 됨 — "매주 월요일 오전 8시, 이메일로"
