STEP 2 · 35분

PRD → 학습 조교 스킬

스킬은 지시문과 자료를 저장해 두고 채팅에서 / 로 불러 쓰는 기능. 매번 처음부터 설명하지 않아도 되는 나만의 학습 조교가 됨.

1PRD를 스킬 내용으로 변환

PRD를 만든 채팅창에 이어서 붙여 넣어도 됨.

프롬프트 ② 스킬 변환
아래 PRD를 바탕으로 Gemini 스킬을 만들 거야. 다음 세 가지를 작성해 줘.

1. 스킬 이름: 20자 이내, 무엇을 하는 조교인지 드러나게
2. 설명: 한 문장
3. 요청 사항(지시문)
   - 구성: 역할 / 대상 / 참고 자료 사용 규칙 / 대화 절차 / 출력 형식 / 금지 사항
   - AI에게 직접 지시하는 문장으로 쓴다. (예: "너는 ~이다", "~한다")
   - PRD에 없는 기능은 추가하지 않는다. ⑧ 실행 조건은 지시문에 넣지 않는다.
   - 1,000자 이내로 쓴다.

마지막에 이 조교가 제대로 동작하는지 확인할 테스트 질문 3개를 따로 적어 줘.
(정답을 바로 달라고 조르는 질문 1개, 자료에 없는 내용을 묻는 질문 1개 포함)

[PRD]
(여기에 완성한 PRD를 붙여 넣기)

2스킬 만들기

Gemini · 학내 계정

스킬로 학습 조교 등록

  1. 왼쪽 사이드바 아래 설정 → 스킬으로 이동
  2. 직접 만들기 선택 → 프롬프트 ②가 만든 이름 · 설명 입력
  3. 지시문을 요청 사항 칸에 붙여 넣기
  4. 강의자료 PDF 첨부
  5. 만들기로 저장
  6. 새 채팅에서 / 입력 → 만든 스킬 선택 → 테스트 질문
이럴 때이렇게
설정에 "스킬" 메뉴가 없음학내 계정에 아직 배포되지 않은 상태. Gem으로 같은 지시문을 등록해 진행(학교 계정의 Gem은 바로 사라지지 않음). Gem도 없으면 새 채팅 맨 앞에 지시문을 붙여 넣고 시작
파일 첨부가 안 됨파일 용량·형식 확인. 안 되면 채팅에서 / 로 스킬을 부른 뒤 같은 대화에 PDF를 올려서 사용
스킬이 / 목록에 안 보임새로고침 후 새 채팅에서 다시 / 입력. 스킬 이름 첫 글자를 이어서 입력하면 걸러짐

3테스트하고 고치기

프롬프트 ②가 준 테스트 질문 3개를 그대로 넣어 봄. 그다음 옆 사람과 노트북을 바꿔 서로의 조교를 3분씩 써 봄.

실패해도 정상. 어긋난 장면이 지시문을 고칠 근거가 됨. 예: 정답을 바로 준다 → 금지 사항에 "내가 두 번 시도하기 전에는 정답을 보여주지 않는다"를 추가하고 스킬을 수정함.
